# Tokyo Bus Mate

日本語が苦手な訪日外国人観光客が、路線バスに乗るときの不安を減らすためのWebサービスです。
バスの系統番号・行き先表示と、降車停留所の日本語名・ローマ字表記を確認できます。

現在のプロトタイプは、都営バス上23系統を利用する次の案内に対応しています。

- 目的地：上野動物園
- 目的地：上野公園
- 目的地：上野駅
- 目的地：上野松坂屋
- 乗車停留所：浅草雷門、浅草一丁目、浅草寿町
- 降車停留所：上野公園山下、上野駅前、上野松坂屋前
- バスの行き先表示：上野松坂屋前

上記の乗降順と同じ便で移動できることは、同梱GTFSデータを使って確認しています。
画面右上のボタンで日本語・英語を切り替えられます。実際の車両表示と照らし合わせるため、
系統番号やバスの行き先表示は日本語のままです。

画面はホーム、行先選択、乗車停留所選択、バス案内に分かれており、
前後の画面へ移動しながら選択内容を確認できます。

## 主な機能

- 登録済みの観光地から目的地を選択
- 選択した目的地に対応する乗車停留所を選択
- ホームから案内までを画面ごとに進めるステップ形式の操作
- 系統番号、行き先表示、乗車停留所を確認
- 乗車停留所から降車停留所までの停車順を確認
- 降車停留所の日本語名とローマ字を確認
- GTFSに記載された運賃を表示
- 日本語・英語の画面表示を切り替え

車両写真は、掲載許可を得た画像を用意するまで仮表示です。
リアルタイムの運行情報、現在地、降車カウントダウンには対応していません。

## 開発者向けルール

### ブランチ運用

- 通常の開発は `dev` ブランチで行います。
- 変更の規模に応じてテストを実行し、動作に問題がないことを確認してから `main` に反映します。
- `main` はGitHub Pagesで公開する安定版として扱い、直接の作業ブランチにはしません。

### コミットメッセージ

コミットメッセージは、次の形式で記述します。

```text
英語の動詞: 変更内容
```

例：

```text
Add: 行先選択ツールの追加。
Fix: 行先が表示されないバグの修正
Update: READMEの文章を変更
```

英語の動詞は変更の内容に合わせて選び、コロンの後には変更内容を簡潔に書きます。

### テストと公開

- 画面変更時は、後述の手順でLive Serverを使って画面を確認します。
- JavaScript変更後は、`npm test` で自動テストを実行します。
- 必要な確認を終えてから `dev` の変更を `main` に反映します。
- `main` に反映した内容をGitHub Pagesで公開します。公開後は実際のページで、JSONの読み込みと主要画面の動作を確認します。

このプロジェクトはHTML・CSS・JavaScript・JSONで動作する静的サイトです。
GitHub Pagesで公開できる構成を維持し、相対パスを使ってプロジェクト用URL配下でも動作するようにします。
秘密情報や公開許可のない写真・データを公開対象へ含めないでください。

### ローカル環境での画面テスト

Git、Visual Studio Code、Live Server拡張機能を使って、ローカルでアプリを起動します。
この手順では、開発作業用の `dev` ブランチをチェックアウトします。

1. リポジトリをクローンし、開発ブランチへ切り替えます。

   ```text
   git clone https://github.com/moris-git/Tokyo-Bus-Mate.git
   cd Tokyo-Bus-Mate
   git switch dev
   ```

2. Visual Studio Codeで、クローンした `Tokyo-Bus-Mate` フォルダーを開きます。
3. 拡張機能ビューで **Live Server**（Ritwick Dey）を検索してインストールします。
4. エクスプローラーから `index.html` を右クリックし、**Open with Live Server** を選びます。
   ブラウザーでローカルサーバー上のアプリが開きます。`index.html` を直接ブラウザーで開かず、
   Live Server経由で起動してください。
5. 次の操作を行い、画面とデータが正しく表示されることを確認します。
   - 「案内をはじめる」から目的地、乗車停留所の順に選び、バス案内まで進む
   - 乗車停留所や目的地への戻る操作、ヘッダーのホーム操作を確認する
   - 日本語・英語を切り替え、選択内容と案内表示が維持されることを確認する
   - 必要に応じてブラウザーの開発者ツールでモバイル相当の画面幅にし、レイアウトを確認する

## 収録データについて

このプロトタイプは、同梱された都営バスGTFSを基に作成した路線・停留所情報を使用します。
データの更新・再加工は行わず、案内内容は現在の収録範囲に限ります。
そのため、実際の運行状況や最新の時刻・運賃を示すものではありません。

## テスト

```text
npm test
```

このテストでは、停留所順序、案内データの組み立て、日本語・英語の翻訳文、
HTMLで使う翻訳キー、GTFSから生成された乗車停留所データを確認します。
各目的地の案内に、乗車停留所から降車停留所まで順序どおりの経路が含まれることも確認します。

## ファイル構成

- `index.html`：共通レイアウトと各画面のHTML構造
- `css/style.css`：画面の見た目
- `js/main.js`：画面遷移、初期化、選択操作、案内表示、言語切り替え
- `js/busService.js`：JSON読み込みとバス案内データの組み立て
- `js/routeUtils.js`：乗車・降車停留所の順序判定
- `js/translations.js`：日本語・英語の画面文言
- `package.json`：自動テストなどのnpmコマンド
- `data/destinations.json`：観光地と路線・停留所の対応表
- `data/bus-routes.json`：同梱GTFSを基にした路線、停留所、運賃、検証情報
- `tests/routeUtils.test.js`：経路判定と生成データのテスト

## データ出典と公開時の注意

- 路線データの出典は、東京都交通局および公共交通オープンデータ協議会の都営バスGTFSです。
- 同梱データに関するライセンス・クレジット表記は、公開ページと配布条件に従います。
- 運賃210円はGTFS記載値です。この路線のIC運賃はGTFSに記載されていません。一般公開前に運行事業者へ運賃ルールを確認してください。
- 車両写真を掲載する場合は、チームで撮影・保有するなど、Web公開の許可を得た画像を使用します。
- 東京スカイツリー最寄りの停留所は、同梱GTFSでは浅草雷門・浅草一丁目・浅草寿町から乗車後に到達する同一便が確認できなかったため、案内対象に含めていません。
